# Work Instruction Portal

Repository untuk **Work Instruction Portal**—portal internal responsif untuk menemukan, membuat, meninjau, dan menerbitkan prosedur kerja.

Aplikasi Laravel berada di folder [`portal`](portal/). Dokumentasi fitur, role, workflow, instalasi lokal, pengujian, dan referensi desain tersedia di [portal/README.md](portal/README.md).

## Sorotan v1.1

- Library publik dengan pencarian dan filter kategori.
- Akses WI IT terbatas untuk pengguna IT dan Admin.
- Workflow review publikasi serta pengajuan penghapusan ke Admin.
- Editor Tiptap, gambar, blok Bash, highlight, dan lampiran PDF privat.
- Dashboard IT dan navigasi sidebar responsif.
